WEBSITE ULANG TAHUN DIAH — PANDUAN PEMULA

1. Buka folder project ini di Visual Studio Code.
2. Buka index.html di browser untuk melihat website.
   Cara paling nyaman: install extension "Live Server" di VS Code,
   klik kanan index.html, lalu pilih "Open with Live Server".
3. Ganti foto:
   - Siapkan 3 foto kalian.
   - Letakkan di assets/images/
   - Namai persis: memory-1.jpg, memory-2.jpg, memory-3.jpg
   - Jika ingin lebih banyak foto, duplikasi elemen <figure class="photo-card"> di index.html.
4. Tambahkan musik:
   - Pilih file audio yang memang boleh kamu gunakan.
   - Letakkan di assets/music/ dan namai our-song.mp3
   - Tombol musik baru akan berfungsi setelah file tersedia.
   - Musik tidak otomatis diputar karena browser meminta interaksi pengguna.
5. Personalisasi:
   - Edit isi surat di bagian <section id="letter"> pada index.html.
   - Edit tanggal/cerita timeline di bagian <section id="story">.
   - Edit pesan amplop di atribut data-message pada tombol class="envelope".
6. Love counter:
   - Tanggal jadian sudah diset ke 4 Januari 2025 di js/script.js.
   - Counter menghitung otomatis sampai tanggal saat website dibuka.
7. Uji di HP:
   - Coba buka melalui browser HP setelah website dipublikasikan.
   - Pastikan foto dan musik sudah dimasukkan.

PUBLISH GRATIS DENGAN GITHUB PAGES
1. Buat akun/login di github.com.
2. Buat repository baru, misalnya diah-birthday.
3. Upload seluruh isi folder project (bukan hanya index.html).
4. Masuk Settings > Pages.
5. Pada Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. Tunggu proses selesai. GitHub akan memberikan URL website.
8. Tes URL tersebut dari HP dan pastikan semua aset tampil.

CATATAN PRIVASI
Website GitHub Pages bersifat publik bagi siapa pun yang memiliki link dan dapat ditemukan jika URL dibagikan/diindeks. Jangan masukkan alamat rumah, nomor telepon, atau informasi pribadi sensitif. Gunakan foto yang kalian berdua nyaman untuk bagikan.
